# 고교선택 가이드

학교알리미 공시 데이터로 **예비고1 고교선택 설명회** 자료를 만드는 학원용 웹앱입니다.
학교를 고르고 시험 특징을 몇 줄 적으면 설명회 슬라이드, 발표 대본, 학부모 배부물(A4 한 장)이 만들어집니다.

## 쓰는 순서

| 단계 | 하는 일 |
| --- | --- |
| 1 학교 고르기 | 시·도, 시·군·구별로 학교 카드를 보고 설명회에서 다룰 학교를 담습니다. 카드의 큰 숫자가 1등급 자리(1학년 × 10%)입니다. |
| 2 해설 입력 | 학교별 시험 특징(과목·유형·수치·시기), 그래서 어떻게 되는지, 대책, 대안을 적습니다. 오른쪽에 발표 문장이 바로 만들어집니다. |
| 3 카피 고르기 | 오프닝 방식(숫자 충격, 한 아이 이야기, 두 학교 갈림길, 제도 변화, 질문)과 첫 문장을 고르고, 발표에 넣을 슬라이드를 켜고 끕니다. |
| 4 발표 | 슬라이드를 눌러 발표합니다. ← → 넘기기, S 대본 보이기/숨기기, F 전체화면, Esc 나가기. |
| 비교 | 학년별 학생 수, 1등급 자리, 레이더 그림, 표. |
| 배부물 | 설명회 끝나고 나눠 드릴 A4 한 장 요약지. 바로 인쇄합니다. |
| 자료 내려받기 | 발표 자료·배부물을 HTML 파일 하나로 받습니다(인터넷 없이 열리고, 인쇄하면 PDF). 작업 백업/불러오기. |

학원 이름, 설명회 제목, 일시, 상담 전화는 오른쪽 위 **설정**에서 바꿉니다.
작업 내용은 그 브라우저에만 저장되므로 다른 컴퓨터로 옮길 때는 **작업 백업**을 쓰세요.

## 데이터

- 출처: [학교알리미](https://www.schoolinfo.go.kr) 공개용데이터 — ‘학년별·학급별 학생수’, ‘학교기본정보’ (고등학교, 전국)
- 1등급 자리 = 1학년 학생 수 × 10%, 소수점 버림 (5등급제). 예전 9등급제 비교는 × 4%.
- 성취도 A 비율, 4년제 진학률은 공개용데이터에 없어서 해설 입력에서 직접 넣습니다.
- 영어 평가계획(`data/plans.js`): 학교알리미 「교과별 교수·학습 및 평가계획」 2026 1학기 1학년 공통영어1 원문을 학교마다 대조해 옮겼습니다. 지금은 **경남 진주시 일반고 13곳**이 들어 있고, 학교를 담으면 평가계획 칸이 자동으로 채워집니다. 다른 학교는 카드의 학교알리미 링크에서 원문을 보고 직접 넣습니다.
- 공시가 새로 나오면 데이터를 다시 받습니다.

```bash
node tools/fetch_data.mjs 2027
```

`data/schools.js`, `data/schools.json` 이 새로 만들어집니다. 커밋하고 push 하면 사이트에 반영됩니다.

## 로컬에서 열기

`index.html` 을 더블클릭해도 열립니다. 내려받기 기능까지 확실히 쓰려면 로컬 서버로 엽니다.

```bash
node serve.mjs
```

→ http://localhost:5233
